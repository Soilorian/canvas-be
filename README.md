# Canvas drawing application

A shared repository for the Java backend and TypeScript frontend of the canvas drawing application.

- The repository root contains the existing backend and its build configuration.
- `frontend/` contains the frontend formerly maintained in `Soilorian/canvas-drawing-app-fe`; use its `package.json` for frontend scripts and dependencies.

The components keep their existing runtime configuration. Consolidation does not change API endpoints or deploy either component.

## History and attribution

The merge retains the original Git histories and existing licenses. Source repositories remain available. See `README.original.md` for the original root documentation and component READMEs for their credits.

No application or model was executed during this consolidation.
